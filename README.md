# cgp_pdhdi
Cartesian Genetic Programming in Processing Degraded Historical Documents Images

Uses :
1. python3 main.py <iterations> <geracoes> <lambda> <nos> <levels_back> <nos_por_camada> <image> <gt> 
Executa e salva as informações de um CGP por n iterações (sem seed)
Quando image e gt = all all, executa sobre todas imagens

2. python3 data_analysis.py <graphic> <image/all> <all/n_iteration>
3. python3 data_analysis.py <graphic> <3> <image/all> <mean/iteration>
